## Depth bar (same as Container Trucking)

Each **deep blog** should aim for ~25–40 min read:

1. Problem framing  
2. India corridor / plant facts  
3. Body class, axle, gate reality  
4. Cost and failure modes  
5. Hybrid capacity model (owned first, labeled overflow)  
6. Checklist or maturity model  
7. FAQ + cluster links + mid-article CTAs  

Each **report** is a **200+ page PDF** (gated download) plus a **1,000–1,500 word crawlable HTML** landing brief (open to Googlebot).
